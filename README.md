json visualizer

A lightweight visual JSON data flow inspector for developers.
Instantly turn any JavaScript object or array into an interactive node-based graph.

✨ Features
🔗 Visualize JSON relationships as connected nodes
🧠 Auto-detect objects, arrays, and primitives
🖱️ Drag canvas freely
🔽 Collapse / expand nodes
🔍 Clean, readable data layout
⚡ Zero dependencies
🧩 Works with Vanilla JS, React.js, Next.js
🛠️ Perfect as a devtool / debugging utility
